# Сценарий → ролик: полный процесс производства короткого видео

Сквозной кейс: от идеи до готового видеоролика 20 секунд с музыкой и титрами.

## Что внутри

```
сценарий-и-промпты.md   — сценарий (4 сцены × 5 сек), титры, промпты для генератора
prompt.txt              — финальный промпт генерации (20 сек одним запросом)
scripts/generate_video.py — отправка задачи, опрос статуса, скачивание mp4
scripts/overlay_titles.sh — наложение титров ffmpeg (полупрозрачные, верх кадра)
videos/rolik-syroi.mp4  — сырая генерация (без титров)
videos/rolik-final.mp4  — готовый ролик (титры, звук)
```

## Как это работает

1. Скрипт `generate_video.py` отправляет промпт в генератор видео через API,
   дожидается готовности (опрос раз в 15 сек) и скачивает mp4.
2. Скрипт `overlay_titles.sh` накладывает титры: полупрозрачные (60 %),
   в верхней части кадра — чтобы служебные плашки плеера не перекрывали текст,
   с плавным появлением. Звуковая дорожка не перекодируется.

## Как запустить

1. Создать файл `.env` рядом со скриптом со строкой
   `PROXYAPI_KEY=ваш_ключ` (ключ не хранится в коде и не публикуется).
2. Изменить промпт — в файле `prompt.txt`.
3. Запуск и параметры:

```
python3 scripts/generate_video.py --prompt-file prompt.txt
python3 scripts/generate_video.py --prompt-file prompt.txt --duration 10 --resolution 720p
zsh scripts/overlay_titles.sh videos/rolik-syroi.mp4 videos/rolik-final.mp4
```

4. Готовый файл появится рядом: `rolik-<дата>.mp4`.

Требования: Python 3, ffmpeg 7+ с фильтром `drawtext` (в свежих сборках
Homebrew ffmpeg 9 его нет — ставьте `brew install ffmpeg@7`).
Внешние зависимости Python: нет (только стандартная библиотека; пакет
`certifi` полезен на macOS — включён в опробованный запуск).

## Результат

`videos/rolik-final.mp4` — вертикальный ролик 20 сек, 480×854, 9:16:
судорожные сборы маленькой семьи → дорога в закат → счастливое море.
Посмотреть сырой и финальный версии можно в папке `videos/`.
